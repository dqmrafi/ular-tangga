# 4.1.17B-2 — Cross-page landscape transition

## Baseline
- Repo: `rohmanaa/ular-tangga`, branch `main`
- Baseline: `1e4493c fix(gameplay): gate portrait before first paint` (HEAD == origin/main, worktree clean)
- Implementation commit: `e9fe139 fix(gameplay): smooth cross-page landscape transition`

## Navigation flow (existing, unchanged)
`lobby.html` (#play) → `mode.html` (kartu Classic → #go → `launchGame`) → `loading.html?to=gameplay&...` → `location.replace('gameplay.html?...')`.
Keluar dari gameplay: `loading.html?to=lobby`. Tidak ada entry point lain ke gameplay (grep `gameplay.html` / `loading.html` / `location.*`).

## Current lifecycle (sebelum fix)
- Semua halaman selain `index.html` memuat `assets/js/landscape.js` di `<head>` (termasuk `loading.html`, `splash.html`).
- Sejak B-1, di perangkat sentuh portrait setiap halaman digate sebelum first paint (`data-ut-gate` + `#ut-rotate.on`).
- `loading.html` melakukan preload lalu `location.replace(dest)` setelah 300 ms **tanpa memeriksa orientasi**.
- `screen.orientation.lock('landscape')` dicoba oleh `landscape.js` di tiap halaman; manifest PWA `orientation: landscape`.

## Root cause
Gate B-1 menyembunyikan gameplay, tetapi dokumen `gameplay.html` tetap **dimuat dan di-bootstrap saat portrait** (renderer/canvas dibuat 390×844, lalu di-resize setelah rotasi). Loading (jembatan visual) juga tersembunyi oleh gate sehingga tidak berfungsi sebagai transisi.
Frame gameplay portrait yang terlihat sudah 0 (hasil B-1); yang tersisa adalah dokumen gameplay yang dimuat pada orientasi yang salah.

## Fix
`game/loading.html` saja (+14/−1): sebelum `location.replace`, bila `to=gameplay` dan `<html data-ut-gate>` ada, tunggu atribut itu dilepas lewat `MutationObserver` (event-based, tanpa polling), baru lanjut (re-check setelah jeda 300 ms). Sumber kebenaran tetap `landscape.js`; tidak ada detektor orientasi kedua.

## Files changed / not changed
- Changed: `game/loading.html`
- Not changed: `game/assets/js/landscape.js`, `game/gameplay.html`, `game/gameplay/*.js`, `#ut-rotate`, `.on`, `data-ut-gate`, breakpoint `max-width:699px`, camera/dice/turn/AFK/dll.

## Browser limitation
`screen.orientation.lock('landscape')` bisa ditolak browser biasa (butuh fullscreen/PWA). Jika ditolak, gate tetap aktif dan `loading.html` menunggu sampai HP diputar; tidak ada loop dan tidak ada pemalsuan keberhasilan. Pada PWA/browser yang mendukung lock, orientasi berpindah lebih dulu lalu atribut gate dilepas dan alur lanjut.
