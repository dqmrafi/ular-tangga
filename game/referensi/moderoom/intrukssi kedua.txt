# REFERENSI GAMBAR PROYEK

Gunakan dua gambar referensi yang tersedia di folder proyek:

Lokasi folder:
`game/referensi/`

File referensi:
- `game/referensi/moderoom/mode.jpg` — referensi halaman pemilihan mode.
- `game/referensi/moderoom/room.jpg` — referensi halaman Game Room.

# INSTRUKSI PENGGUNAAN REFERENSI

**1. mode.jpg**
- Gunakan sebagai referensi dasar untuk merevisi halaman pemilihan mode yang sudah ada.
- Pertahankan identitas visual, karakter desain, dan elemen yang masih relevan.
- Perbarui layout dan fitur mengikuti spesifikasi terbaru pada prompt.
- Terapkan pemilihan map berbentuk centered horizontal carousel dengan CSS Scroll Snap.
- Gunakan hanya dua card utama: Quick Start dan Create Room.
- Terapkan pilihan Solo, Team, VS Computer, Multi Player, serta Create Room sesuai alur terbaru.
- Hilangkan menu Tournament.

**2. room.jpg**
- Gunakan sebagai referensi dasar untuk halaman Game Room.
- Pertahankan karakter visual dan komposisi layout yang masih relevan.
- Revisi susunan panel mengikuti spesifikasi terbaru:
  - Kiri: Power Shop, kapasitas maksimal 5 Power.
  - Tengah: Character Preparation (Skin, Frame, Dice).
  - Kanan: Player List dan status Ready.
  - Bawah: tombol READY / START sesuai kondisi room.

# PRIORITAS REVISI

1. Revisi desain dan implementasi mode yang sudah ada, bukan membuat halaman baru yang terpisah atau mengganti seluruh identitas visual.
2. Gunakan versi spesifikasi terbaru sebagai acuan fitur dan alur.
3. Gunakan `mode.jpg` dan `room.jpg` sebagai referensi visual masing-masing halaman.
4. Pertahankan komponen lama yang masih sesuai.
5. Perbaiki komponen yang tidak sesuai dengan spesifikasi terbaru.
6. Jangan mengembalikan fitur lama yang sudah dihapus, terutama Tournament.
7. Pastikan navigasi antara Mode Selection dan Game Room tetap terintegrasi dengan sistem game yang sudah ada.

Hasil akhir adalah revisi dari UI game yang sudah tersedia dengan fitur terbaru, bukan desain ulang yang mengabaikan implementasi sebelumnya.
