Buat desain UI game Snakes & Ladders bergaya Minecraft Casual Mobile Game dengan visual kartun 3D, panel kayu, outline tebal, tombol glossy, warna cerah, bevel membulat, dan pencahayaan lembut.

Pertahankan identitas visual game secara konsisten. Gunakan layout yang rapi, proporsional, mudah dibaca, dan tidak terlalu ramai.

# SCREEN 1 — MODE SELECTION

Bagian header:
- Tombol Back di kiri atas.
- Judul halaman di tengah.
- Tombol Home di kanan atas.

[ SELECT MAP — HORIZONTAL CAROUSEL ]

- Letakkan pemilihan map di bagian atas.
- Gunakan horizontal carousel dengan CSS Scroll Snap.
- Map terpilih harus selalu berada tepat di tengah.
- Map di kiri dan kanan tetap terlihat sebagian.
- Map aktif memiliki outline, glow, atau highlight yang jelas.
- Sediakan navigasi swipe dan tombol panah.
- Jangan menggunakan grid map.

[ QUICK START — CARD BESAR KIRI ]

Deskripsi: Main cepat melalui matchmaking.

Pilihan di dalam card:
1. SOLO
   - Ketika diklik, card melakukan flip animation.
   - Tampilkan pilihan 2 pemain, 3 pemain, dan 4 pemain.
   - Setelah jumlah pemain dipilih, mulai Ranked matchmaking.

2. TEAM
   - Mode pertandingan 2 vs 2.
   - Langsung masuk matchmaking Team.

[ CREATE ROOM — CARD BESAR KANAN ]

Deskripsi: Buat pertandingan dengan pengaturan sendiri.

Tampilkan tiga pilihan:
1. VS COMPUTER
   - Bermain melawan komputer atau AI.
2. MULTI PLAYER
   - Bermain bersama beberapa pemain menggunakan satu perangkat yang sama.
3. CREATE ROOM
   - Membuat room online dan mengundang teman menggunakan link atau kode.

Ketika CREATE ROOM diklik, card melakukan flip animation dan menampilkan pilihan:
- SOLO
- TEAM

Setelah format dipilih, lanjutkan ke pembuatan room.

Tidak ada menu Tournament.

# SCREEN 2 — GAME ROOM

Gunakan layout tiga kolom dengan komposisi seimbang.

[ KOLOM KIRI — POWER SHOP ]

- Menampilkan daftar Power yang bisa dibeli.
- Setiap Power memiliki ikon, nama, dan harga.
- Pemain dapat membeli dan memilih Power untuk dibawa ke pertandingan.
- Kapasitas maksimal Power adalah 5.
- Tampilkan indikator slot, misalnya 3/5.
- Tampilkan Power yang sudah dimiliki.
- Jika slot penuh, pembelian Power tambahan tidak dapat dilakukan sebelum pemain mengosongkan slot.

[ KOLOM TENGAH — CHARACTER PREPARATION ]

- Tampilkan preview karakter Minecraft sebagai fokus utama.
- Pemain dapat memilih dan mengganti Skin.
- Pemain dapat memilih Frame.
- Pemain dapat memilih Dice Skin.
- Sediakan tombol Change atau Customize.
- Tampilkan pilihan dalam panel yang rapi dan mudah dipahami.
- Jangan mengubah atau menghilangkan karakter 3D yang sudah ada pada implementasi asli.

[ KOLOM KANAN — PLAYER LIST ]

- Tampilkan daftar seluruh pemain dalam room.
- Setiap pemain memiliki avatar, nama, level, dan status Ready.
- Tampilkan slot kosong jika kapasitas pemain belum terpenuhi.
- Status slot dapat terkunci atau terbuka berdasarkan jenis room.
- Gunakan tampilan slot pemain yang jelas dan konsisten.

Aturan player slot:
- VS Computer: slot bot mengikuti jumlah peserta yang dipilih.
- Multi Player: slot pemain lokal mengikuti jumlah peserta yang dipilih.
- Create Room Privat: hanya host dan pemain yang diundang dapat bergabung.
- Create Room Publik: pemain lain dapat bergabung selama slot masih tersedia.

[ BOTTOM ACTION AREA ]

- Tampilkan tombol READY.
- Tampilkan status kesiapan pemain.
- Host dapat memulai pertandingan setelah persyaratan jumlah pemain terpenuhi dan pemain yang diwajibkan sudah Ready.
- Tombol Start Game hanya aktif ketika seluruh persyaratan terpenuhi.

# ATURAN DESAIN

1. Jangan menambahkan menu Tournament.
2. Jangan membuat pemilihan map dalam bentuk grid.
3. Carousel map harus menggunakan konsep center-focused selection dengan Scroll Snap.
4. Hanya gunakan dua card besar pada halaman pemilihan mode.
5. Gunakan flip animation untuk pilihan Solo dan Create Room sesuai instruksi.
6. Jangan mencampur Quick Start dengan Create Room.
7. Pastikan perbedaan VS Computer, Multi Player, dan Create Room mudah dipahami.
8. Jangan menambahkan fitur yang tidak disebutkan.
9. Pertahankan hierarki visual, spacing, alignment, dan ukuran komponen secara konsisten.
10. Jangan membuat layout terlalu padat atau menggunakan dekorasi berlebihan.

Hasil akhir harus terlihat seperti UI game casual premium bertema Minecraft, dengan UX yang jelas dan siap dijadikan acuan implementasi HTML/CSS.
